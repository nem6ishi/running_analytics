🔥 ポイント走 (スピード持久) VO2max / 乳酸処理

1km交代走（疾走⇄つなぎ）

1km疾走と1kmつなぎジョグを交互に繰り返す。Garminの1kmオートラップと完全連動し、時計操作不要で集中できる実践的インターバル。

疾走区間 4:40〜4:55/km (HR 172〜182)
つなぎ区間 6:20〜6:50/km (HR 145〜155)
本数・構成 3kmアップ ➔ 3〜4本 ➔ 2kmダウン
🧬 生理学的効果:

疾走で発生した乳酸をつなぎジョグでエネルギーとして再利用する「乳酸シャトル機構」を劇的に強化。後半の粘り強さと最大酸素摂取量を高めます。

🌟 ポイント走 (LT向上) 乳酸閾値 (LT)

LTテンポ走（閾値ペース走）

乳酸が急増し始める直前のギリギリ「快適なキツさ」を保って巡航。10kmサブ50およびハーフマラソン巡航速度のベースを作る要のトレーニング。

巡航ペース 5:05〜5:25/km
適正LT心拍 168〜174 bpm (上限目安 176bpm)
距離構成 3kmアップ ➔ 5〜7km巡航 ➔ 1kmダウン
🧬 生理学的効果:

乳酸が蓄積し始めるペースラインを引き上げ、5:25〜5:35/km前後の速度でも息が上がらず「楽に速く巡航できる体質」を獲得します。

🌟 ポイント走 (フル本番特化) Marathon Pace

Mペース持続走（本番ペース走）

NAHAマラソンの目標巡航ペース（サブ4.5）で12〜18kmを持続。リズムの自動化と補給（ジェル・給水）の実戦テストを行う。

目標ペース 6:00〜6:20/km
目標心拍 148〜156 bpm
距離目安 12km 〜 18km (単一巡航)
🧬 生理学的効果:

レース本番のペース配分を身体に刻み込み、無駄な筋力消費を抑えるランニングエコノミーを確立。心拍ドリフトの抑制限界を検証します。

🐢 スタミナ土台 (最重要) Long Slow Distance

本格LSD（超長距離走）

心拍ゾーン2を厳格に維持し、2時間以上走り続ける。毎週スタックすることで心肺と筋肉の土台を作り上げる最重要メニュー。

ペース目安 7:15〜7:45/km (タイム無視)
心拍ゾーン 138〜148 bpm (Zone 2)
走行距離・時間 15〜21.1km (100〜160分)
🧬 生理学的効果:

筋細胞の毛細血管拡張、ミトコンドリア密度の増大、心臓の拡張（スポーツ心臓化）、脂肪酸化利用効率の劇的な向上をもたらします。

🏃‍♂️ 基礎・リカバリー Active Recovery

イージージョグ（回復走）

ポイント走や長距離走の合間に挟む軽めの有酸素走。血流を促して疲労物質を排出しつつ、週間走行距離（マイレージ）を安全に稼ぐ。

ペース目安 6:30〜7:15/km
心拍ゾーン 130〜142 bpm (Zone 1〜2)
距離目安 5km 〜 8km
🧬 生理学的効果:

筋肉の柔軟性維持、全身の血流促進（アクティブリカバリー）、関節・腱の衝撃耐性向上。心身のリフレッシュに最適です。

⚡️ フォーム・神経系強化 Strides / Economy

ウィンドスプリント（流し）

イージージョグの最後に行う100m程度の疾走。力まず大きなフォームで、85〜90%のスピードで気持ちよく駆け抜ける（2〜4本）。

疾走ペース 4:00〜4:30/km (85〜90%)
本数・間隔 100m × 2〜4本 (歩き完全回復)
意識ポイント 大きな股関節伸展・大臀筋のバネ
🧬 生理学的効果:

ジョグで縮こまりがちなフォームをリセットし、速筋線維と運動神経の伝達を刺激。ストライドを自然に広げランニングエコノミーを飛躍させます。

📈 ペーシング・脚作り Progressive Run

ビルドアップ走（漸進加速走）

ゆったりしたジョグペースからスタートし、段階的にペースを上げて最後はLT〜レースペース以上でフィニッシュする実戦練習。

序盤 (1〜4km) 6:30〜6:45/km (HR 135〜142)
中盤 (5〜7km) 6:00〜6:15/km (HR 145〜153)
終盤 (8〜10km) 4:55〜5:10/km (HR 170〜178)
🧬 生理学的効果:

疲労が蓄積した後半に速筋を動員する訓練となり、レース本番で後半に失速せず「ネガティブスプリット（後半型）」で走り切る能力を養います。

🎯 レース直前調整 Tapering / Opener

最終刺激入れ（前々日ミニ刺激）

レース2〜3日前に実施。疲労を溜めずに神経伝達と心肺に短いカツを入れ、本番で序盤からスムーズに動ける身体状態を整える。

全体構成 2kmアップ ➔ 1km刺激 ➔ 1kmダウン
刺激区間ペース 5:15〜5:25/km (ハーフ目標ペース)
総距離 4km前後 (余力を残して終了)
🧬 生理学的効果:

テーパリング（疲労抜き）期間中の心肺・神経の鈍りを防ぎ、筋グリコーゲンの蓄積を邪魔せずに交感神経系を適度に覚醒させます。

🛌 超回復・休養 Supercompensation

完全休養 / アクティブレスト

走らないことも強くなるための不可欠なトレーニング。破壊された筋線維や枯渇したエネルギーを満たし、一段上の走力を定着させる。

休息種別 完全オフ or 軽い散歩・ストレッチ
栄養・睡眠 高タンパク・炭水化物補給 / 7.5h睡眠
重要マインド 「休む勇気」が次の爆発力を生む
🧬 生理学的効果:

グリコーゲンの再充填、結合組織（腱・靭帯）の修復、慢性炎症の鎮静化、自律神経の回復をもたらし、トレーニング効果を定着させます。
