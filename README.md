# Running Analytics (Garmin Data Analytics & Coaching)

Garmin Connect の走行データ（CSV & FITファイル）を解析し、科学的トレーニング指標・レース予想・個別ランの詳細分析＆コーチングを提供するパーソナルダッシュボードです。

---

## 🌟 主な機能

### 1. 科学的トレーニング指標 & レース予想
- **ジャック・ダニエルズ式 VDOT 算出**:
  - 全走撃データから酸素消費量と稼働比率の連立方程式を解き、現在の実力VDOTおよびベストVDOTを精密算出。
  - **5大トレーニングペース（E / M / T / I / R）** を自動提示（イージー、マラソン、閾値/LT、インターバル、レペティション）。
  - 5km / 10km / ハーフ / フルマラソンの高精度レース予想タイムを表示。
- **10km 50分（サブ50）達成プログレストラッカー**:
  - 目標タイム（50:00 / 5:00/km）に対する達成進捗率（%）とタイムギャップ（秒数・ペース差）を可視化。
  - 直近の練習データから「キロ5分以内を連続維持できた最長距離」を自動トラッキング。
- **有酸素デカップリング（Aerobic Decoupling: Pw:Hr / Pa:Hr）**:
  - ランの前半と後半における「効率係数（EF: ペース/心拍数）」の低下率（ドリフト率 %）を算出。
  - 心拍ドリフトの度合いを S / A / B / C の4段階で定量評価し、有酸素ベーススタミナの仕上がり度を診断。

### 2. インタラクティブ・ダッシュボード
- **Cockpit (総合ダッシュボード)**:
  - サブ50目標進捗、VDOT、4大KPI、自己ベスト、週間負荷（前週比+10%ルール）、年間走行カレンダーヒートマップ、および**パフォーマンス推移 & 相関トレンド（過去30日ローリング移動合計／月別カレンダー切り替え、ペース心拍推移、有酸素効率散布図、ピッチ歩幅推移）**を1画面に統合して俯瞰可能。
- **過去30日間ローリング走行ボリューム (スライディングウィンドウ)**:
  - カレンダー月毎のリセットに縛られず、各日における直近30日間の合計走行距離と出走回数の推移を滑らかなエリア曲線で可視化。現在の有酸素ベース蓄積量や過去のピーク値をひと目で把握可能。
- **年間走行カレンダーヒートマップ**:
  - 過去1年間の走行実績を GitHub の草風カレンダーでグラフィカルに表示。月ヘッダー表示、月曜始まりの曜日ラベル、月初日（1日）マーカー、および月別サマリーバッジ（ホバー連動ハイライト＆月固定フィルター）により、各月の走行量・推移・日ごとの詳細データを直感的に把握可能。
- **ラン比較モード (Compare Runs)**:
  - 2つのランニングを選択して1つのグラフ上に重ね合わせ比較（ペース・心拍数・ピッチ・歩幅）。
  - 各種サマリー指標（距離・ペース・心拍数・EF・デカップリング等）の差分テーブルを表示。
- **折れ線グラフ標高オーバーレイ**:
  - ペース・心拍数等の詳細チャートの背景に標高プロファイル（勾配）を薄紫色の山なりエリアとしてオーバーレイ表示。上り坂・下り坂によるペースや心拍の変動を直感的に把握可能。
- **アクティビティ履歴のリアルタイム検索＆動的ソート**:
  - キーワード検索ボックスによる瞬時の絞り込み。
  - 各列（日付、タイトル、距離、タイム、ペース、心拍数、EF、デカップリング等）のクリックによる昇順・降順ソート。
- **プライバシー配慮**:
  - GPS走行ルート地図は一切表示せず、純粋なパフォーマンス分析に特化。

## 🏃 自動データ同期の使い方

Garmin Connect から未取得のランニングデータ（FITファイル＆アクティビティ概要）を自動ダウンロードし、ダッシュボードの更新まで一気通貫で行えます。

### 1. 同期コマンドを実行
```bash
uv run python sync.py
```
- **初回実行時**:
  Garmin Connect のメールアドレス・パスワード（および2段階認証コード）の入力を求められます。
  認証に成功すると、ローカル（`.garmin_tokens/`）に安全な認証トークンが保存されます。
- **2回目以降**:
  保存されたトークンで自動ログインするため、パスワード入力不要で一瞬で同期が完了します。

### 2. 同期と同時に GitHub Pages に push する場合
```bash
uv run python sync.py --push
```
新規データを取得後、自動で `build.py`（HTML生成）を実行し、リモートの最新状態を取り込んだ上で `docs/` を GitHub に push します。push されると GitHub Pages が自動更新されます。

### 主なオプション
- `--all`: **過去の全ランニングデータを対象に同期**（未ダウンロードの過去FITファイルも一括取得）
- `--limit <件数>`: チェックする直近アクティビティの件数（デフォルト: 15）
- `--relogin`: キャッシュされたトークンを破棄して再ログイン
- `--no-build`: データのダウンロードのみ行い、ビルドをスキップ
- `--push`: 同期＆ビルド完了後に GitHub へ自動 push（GitHub Pages に反映）
- `--open`: ビルド完了後にブラウザでダッシュボード (`docs/index.html`) を開く

## ⏰ 定期自動同期のセットアップ (macOS launchd)

macOS の `launchd` を使用して、毎日定時（21:00）にローカル環境で `sync.py --push` を自動実行できます。同期・ビルドされたダッシュボードは自動的に GitHub へ push され、GitHub Pages に最新データが公開されます。

### セットアップ手順
```bash
./scripts/install_launchd.sh
```
- `uv` の絶対パスおよびプロジェクトディレクトリを自動解決し、`~/Library/LaunchAgents/com.nem6ishi.running-sync.plist` にジョブを登録します。
- 実行ログは `logs/sync.log` に出力されます。

### アンインストール手順
```bash
./scripts/install_launchd.sh --uninstall
```
- ジョブの登録を解除し、plist 設定ファイルを削除します。

## ⚙️ 目標・生理学的パラメータの設定 (`config.py`)

ランナー個人の目標や最大心拍数などの設定は `config.py` で一元管理されています。必要に応じて数値を変更できます。

```python
# config.py
TARGET_DISTANCE_KM = 10.0      # 目標距離 (km)
TARGET_TIME_SECONDS = 3000     # 目標タイム (秒: 50分 = 3000秒)
MAX_HEART_RATE = 195           # 最大心拍数 (bpm)
RESTING_HEART_RATE = 50        # 安静時心拍数 (bpm)

# 心拍ゾーン定義 (Z1〜Z5)
HR_ZONES = [
    {"name": "Z1 回復 (Easy)", "min_ratio": 0.50, "max_ratio": 0.60, ...},
    {"name": "Z2 有酸素 (Base)", "min_ratio": 0.60, "max_ratio": 0.70, ...},
    {"name": "Z3 ペース (Tempo)", "min_ratio": 0.70, "max_ratio": 0.80, ...},
    {"name": "Z4 閾値 (Threshold)", "min_ratio": 0.80, "max_ratio": 0.90, ...},
    {"name": "Z5 最大 (VO2Max)", "min_ratio": 0.90, "max_ratio": 1.00, ...},
]
```
